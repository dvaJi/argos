# @argos/landing

Marketing landing page for Argos, built with [TanStack Start](https://tanstack.com/start) and deployed to [Cloudflare Workers](https://developers.cloudflare.com/workers/framework-guides/web-apps/tanstack-start/).

## Stack

- **TanStack Start** (React 19 + TanStack Router, SSR)
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Cloudflare Workers** via `@cloudflare/vite-plugin`

## Develop

From the repo root:

```bash
pnpm --filter @argos/landing dev
```

Open <http://localhost:3000>.

## Build

```bash
pnpm --filter @argos/landing build
```

Output lands in `.output/` (Workers-compatible server entry + static assets).

## Type check

```bash
pnpm --filter @argos/landing typecheck
```

## Deploy

```bash
pnpm --filter @argos/landing deploy
# equivalent to: build && wrangler deploy
```

The Worker serves the custom domain **argos.aipurrjects.xyz** (configured via
`routes` in `wrangler.jsonc`). On first deploy, Cloudflare provisions the custom
domain DNS record automatically — make sure the `aipurrjects.xyz` zone is active
in your Cloudflare account.

## GitHub OAuth relay

`GET /auth/github/callback` is a stateless relay that finishes GitHub Copilot's
traditional OAuth flow for the desktop app: it exchanges GitHub's authorization
`code` for an `access_token` **server-side**, then redirects to
`argos://auth/callback?token=...` so the running desktop app receives the token.

The `client_secret` never ships in the desktop binary — it lives only on the
Worker. Configure it once:

```bash
pnpm --filter @argos/landing exec wrangler secret put GITHUB_CLIENT_SECRET
```

`GITHUB_CLIENT_ID` and `OAUTH_DEEPLINK_SCHEME` are public `vars` in
`wrangler.jsonc`. Regenerate runtime types after changing them:

```bash
pnpm --filter @argos/landing cf-typegen
```

## Project layout

```
src/
├── components/    # Section components (Hero, Features, Providers, Download, Footer)
├── routes/        # TanStack Router file-based routes
│   ├── __root.tsx # Root route: <head>, shell, global CSS
│   └── index.tsx  # Landing page composition
├── styles/        # Tailwind v4 + Argos theme tokens
├── router.tsx     # getRouter() factory
└── routeTree.gen.ts  # Auto-generated (do not edit)
```

`routeTree.gen.ts` is regenerated by the TanStack Router plugin on `dev` and `build`.
