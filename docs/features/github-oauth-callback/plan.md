# Plan — GitHub OAuth Callback Relay

## Flow

```
Desktop (OAuthPresenter.startGitHubCopilotLogin)
  │  generate state, register pending {state, providerId, resolve, reject}
  │  shell.openExternal(github.com/login/oauth/authorize?...&redirect_uri=<landing>/auth/github/callback&state=...)
  ▼
GitHub (user authorizes)
  │  302 → https://argos.aipurrjects.xyz/auth/github/callback?code=...&state=...
  ▼
Landing Worker (GET /auth/github/callback)
  │  POST github.com/login/oauth/access_token {client_id, client_secret(env), code, redirect_uri}
  │  → { access_token }
  │  302 → argos://auth/callback?token=<access_token>&state=<state>
  ▼
Desktop OS → Electron (open-url / second-instance)
  │  DeeplinkPresenter.handleDeepLink("argos://auth/callback?token=...&state=...")
  │  → OAuthPresenter.completeGitHubAuthFromDeepLink({token, state})
  │     match pending state (CSRF), validate token, store apiKey, emit providerUpdated
  ▼
Renderer (providerUpdated) → UI shows connected
```

## Affected Files

### Landing (`apps/landing`) — new
- `src/routes/auth/github/callback.tsx` — `createFileRoute("/auth/github/callback")` with `server.handlers.GET`: reads `code`/`state`/`error`, exchanges code server-side via `env.GITHUB_CLIENT_SECRET`, returns a 302 `Response` to `argos://auth/callback?...`. Renders a minimal fallback HTML body for non-redirect clients.
- `src/lib/githubOAuth.ts` — pure helper: `exchangeCodeForToken({code, clientId, clientSecret, redirectUri})` → `POST` to GitHub, returns `{access_token}` or throws.
- `wrangler.jsonc` — add `vars: { GITHUB_CLIENT_ID, OAUTH_DEEPLINK_SCHEME: "argos" }`. Secret `GITHUB_CLIENT_SECRET` set out-of-band via `wrangler secret put`.
- `routeTree.gen.ts` — regenerated by the router plugin on build/dev; placeholder left in place.
- `worker-configuration.d.ts` — optional, generated by `wrangler types` (`cf-typegen`); document env shape.

### Desktop (`apps/desktop`) — modify
- `src/main/presenter/githubCopilotOAuth.ts` — drop `clientSecret` from config, drop the `BrowserWindow`-based `startLogin` and `exchangeCodeForToken`. Keep `validateToken`. Add `buildAuthUrl(state)` and a static `generateState()`. `createGitHubCopilotOAuth` no longer throws on missing secret.
- `src/main/presenter/oauthPresenter.ts` — add `pendingAuths: Map<state, {providerId, resolve, reject, timer}>`. Rewrite `startGitHubCopilotLogin` to: build URL, register pending (5-min timeout), `shell.openExternal`, await promise, validate, store, emit. Add `completeGitHubAuthFromDeepLink({token?, state?, error?})`.
- `src/main/presenter/deeplinkPresenter/index.ts` — add `auth`/`callback` branch to the command switch → `handleAuthCallback(params)` → `presenter.oauthPresenter.completeGitHubAuthFromDeepLink(...)`. No raw-token logging.
- `src/shared/types/presenters/legacy.presenters.d.ts` — add `completeGitHubAuthFromDeepLink` to `IOAuthPresenter`.
- `.env.example` — remove `VITE_GITHUB_CLIENT_SECRET` requirement for desktop (now a Worker secret); keep `VITE_GITHUB_CLIENT_ID` and `VITE_GITHUB_REDIRECT_URI`.

## Interfaces

`IOAuthPresenter` gains:
```ts
completeGitHubAuthFromDeepLink(payload: { token?: string; state?: string; error?: string }): void;
```
`GitHubCopilotOAuth` config loses `clientSecret`; gains `buildAuthUrl(state: string): string` + `static generateState(): string`.

## Security

- `state` nonce generated per login, matched on callback (CSRF). Unmatched/duplicate states are dropped.
- `client_secret` lives only in the Worker; never bundled, never sent to the client.
- Deep-link `token` param is not logged (reuse `redactSearchParamsForLog` / explicit redaction).
- 5-minute expiry on pending requests; stale entries cleared on resolve/reject/timeout.

## Test Strategy

- **Landing**: `typecheck` + `build`; manual `curl` against a local `vite dev` callback with a fake `code` to confirm it attempts the exchange and returns a 302 to `argos://`.
- **Desktop**: `typecheck`; the device flow (unchanged) remains the primary regression anchor. Manual: trigger traditional login, complete in system browser, confirm token lands on provider.
- **Lint**: root `pnpm run lint` (architecture + agent-cleanup + oxlint) unchanged.

## Compatibility

- Device Flow path is untouched — users who can't use the relay still log in.
- `apiKey` storage semantics unchanged (token stored as before).
- The generic `startOAuthLogin` (localhost server) is untouched.
- No IPC contract change for the renderer — `startGitHubCopilotLogin(providerId): Promise<boolean>` signature is unchanged.
