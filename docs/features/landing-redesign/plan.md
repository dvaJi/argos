# Plan: Landing page redesign

## Architecture decisions

- Keep the stack: TanStack Start (SSR) + Tailwind v4 + `@phosphor-icons/react`.
- Add `vgpu@0.3.1` (WebGPU) as a client-side dependency for the hero shader
  backdrop. Dynamic `await import("vgpu")` inside a React `useEffect` keeps
  the module out of the SSR bundle; Vite's Rolldown code-splits it into a
  separate chunk (`dist-*.js`, ~136 KB gzipped ~43 KB).
- Keep component-per-section structure under `src/components/`; add three
  components:
  - `CopyCommand.tsx`: client-side copy-to-clipboard command chip
    (mono text + copy button, "Copied" feedback). Shared by the hero CTA,
    agents section, and the download section.
  - `Agents.tsx`: the agent-first section (`#agents`).
  - `ShaderBackdrop.tsx`: WebGPU background effect for the hero. Server
    renders a hidden `<canvas>` (no SSR GPU work); client hydrates in
    `useEffect` with dynamic `import("vgpu")`. Fallback chain:
    - `navigator.gpu` absent → skip (CSS gradient stays)
    - `prefers-reduced-motion: reduce` → skip
    - `init()` throws (no adapter / permission denied) → `catch` → canvas
      invisible, CSS gradient stays
    - `IntersectionObserver` watches the canvas; when `isVisible` is false
      the frame loop short-circuits (no GPU work offscreen)
    - `pointermove` on `window` (passive) drives a smoothly-lerped uniform
      (no React state, no `useState` re-render per pointer event)
- Keep `Reveal.tsx` / `useInView` (IntersectionObserver) for scroll reveals;
  entrance motion stays CSS keyframe-based. Remove unused `.animate-marquee`
  and `.gradient-text` CSS.
- Page order: Hero -> Providers (trust strip) -> Agents -> Features ->
  Spotlight -> Download. Layout families per section stay distinct (split,
  logo grid, docs rows, bento, full-width media, install panel).
- Nav gains an "Agents" link; labels otherwise unchanged. Footer unchanged
  except tagline alignment with README positioning.

## Content rules

- One accent (cyan), one radius system (pill buttons / 16px cards / 12px code
  blocks), dark theme only.
- Eyebrow budget: hero badge + agents section label only.
- Every command and settings path on the page is verified against the repo
  (`docs.tsx`, README, UI settings components).
- Copy re-read for the AI-tell audit: no em-dashes, no filler verbs, no fake
  numbers, no decorative dots.

## Test strategy

- Landing has no unit test suite; validation is `typecheck`, `vite build`,
  `bun run format`, `bun run lint` (repo guards included), and manual visual
  review of the dev server.
- The WGSL shader (`panoptes.wgsl`) is validated offline with `npx vgpu check`
  (reflection + WGSL diagnostics) and rendered headlessly via `vgpu/node` to a
  PNG (pixel-level visual verification in the scratchpad lab).

## Risks

- Route tree regeneration: `routeTree.gen.ts` is auto-generated by the router
  plugin on dev/build; no manual edits.
- Cloudflare deploy unchanged (same `wrangler.jsonc`, no worker code touched).
- vgpu loads a Dawn WASM/native binary at runtime; the dynamic import ensures
  this never blocks SSR or the initial parse.
