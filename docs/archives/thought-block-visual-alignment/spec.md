# Thought Block Visual Alignment

## Goal

Make the thought block look visually consistent with the command/tool-call cards in the assistant message stream.

## Acceptance Criteria

- The thought block uses the same general card language as nearby command/tool-call UI.
- The header row feels aligned in spacing, typography, and icon treatment.
- Existing collapse behavior and loading state remain unchanged.

## Non-Goals

- Changing thought block behavior.
- Redesigning all message block styles.
