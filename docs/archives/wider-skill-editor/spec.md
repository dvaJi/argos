# Wider skill editor

## User need

The Edit Skill sheet needs more horizontal room for skill content, runtime settings, environment variables, scripts, and file paths.

## Goal

Increase the editor's desktop width while preserving its responsive mobile behavior.

## Acceptance criteria

- The Edit Skill sheet grows beyond its current 672px desktop cap.
- The sheet remains constrained by the viewport and retains the existing small-screen behavior.
- No shared Sheet defaults or other sheets are changed.

## Constraints

- Use the existing Sheet primitive and Tailwind width scale.
- Do not change the form behavior or data flow.
